# brianESte.github.io
The current main focus of this site is a comparison of simgle winner voting methods. 

## Morse Code page
A remake of <span>Morsecode.io</span> (receive only). A cool page for learning to send Morse code can be found [here](https://morse.withgoogle.com/learn/). Word selection was facilitated with the scripts `filter_word.sh` and `score_word.sh`. The HTML / CSS _could_ be more compact, but chromium has a bug that hinders the usage of `<foreignObject>` in `<svg>`s.


## Other notable pages:
* Simple Plurality page:        Exhibit how SP works, and its issues
* Instant Runoff Voting page:   Exhibit the pros and cons of IRV
* Approval Voting page:         Exhibit the pros and cons of AV
